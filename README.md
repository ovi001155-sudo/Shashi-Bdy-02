## 🔍 What Is This?

**Romantic Love Tree** is a free, open-source **love confession webpage** that you can personalize and deploy for your partner. Simply edit the config file with your names, your special date, and a custom love poem — then share the link. Your partner sees a magical animated tree growing with heart-shaped blossoms, a typewriter-style love message, and a live counter showing how long you've been together.

**Perfect for:**
- 💝 Valentine's Day love letters
- 💍 Anniversary gifts & surprises
- 🎂 Birthday romantic messages
- 💌 Love confessions & proposals
- 🌹 Long-distance relationship gestures

## ✨ Experience Flow

The experience opens with the animated Birthday Gift card, then fades into the Love Tree. Click the seed on the Love Tree screen to start its growth animation.

```
Birthday Gift opens and animates 💘
             →  Pink birthday wish holds, then fades into the Love Tree 🎂
             →  Click the seed to grow the heart tree 🌳
             →  Love poem and relationship timer appear 📜⏱️
```

## ⚙️ Configuration Guide (`config.js`)

Customize your names, date, and poem directly in `config.js`:

```javascript
var config = {
    lines: [
        "My dearest love,",
        "In a world full of stars, your light outshines them all.",
        "Every petal that falls carries a whisper of my devotion.",
        "Your sweet smile is the rhythm of my heart.",
        "Time stands still whenever I hold your hand.",
        "You are my today, my tomorrow, and my forever.",
        "I will love you for all eternity...",
    ],
    date: "2026-05-13T06:12:05",   // Format: YYYY-MM-DDTHH:mm:ss
    names: ["Me", "Lishu"]
}
```

## 🚀 Getting Started

No installation or build tools required.

1. **Download or clone** this repository
2. **Open** `index.html` in any modern web browser
3. Watch the love tree bloom!

```bash
# Optional — serve locally with Python
python -m http.server 8080
# Then open http://localhost:8080
```

> ✅ 100% Mobile & Desktop Compatible — Tested on Chrome, Firefox, Safari, Edge.
